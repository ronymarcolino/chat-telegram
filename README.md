# chat-telegram

A Telegram bot that answers messages with an LLM. The bot runs with `python-telegram-bot`, keeps a per-chat conversation history in memory, and can use either a local Ollama model or an external OpenAI-compatible API such as NVIDIA NIM.

![Chat Telegram Bot](/image/telegram-chat-ollama.png)

## How It Works

1. A user sends a message to the Telegram bot.
2. The bot stores the message in the chat history for that Telegram chat.
3. The message history is sent to the configured LLM provider.
4. The model response is returned to the user in Telegram.

The default provider is Ollama with the `qwen3:4b` model, and the bot runs in polling mode.

## Requirements

- Python 3.13+
- [uv](https://docs.astral.sh/uv/) or `pip`
- [Ollama](https://ollama.com/) installed and running locally
- A Telegram bot token from BotFather

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd chat-telegram
```

### 2. Create the environment file

Create a `.env` file in the project root:

```env
TELEGRAM_TOKEN="your_telegram_bot_token"
```

Optional settings:

```env
LLM_PROVIDER="ollama"
LLM_MODEL="qwen3:4b"
LLM_REQUEST_TIMEOUT_SECONDS="60"
OLLAMA_MODEL="qwen3:4b"
OLLAMA_THINK="true"
OLLAMA_HOST="http://host.docker.internal:11434"
```

### 3. Install dependencies

Using `uv`:

```bash
uv sync
```

Using `pip`:

```bash
pip install -e .
```

### 4. Start Ollama and pull the model

Make sure the Ollama service is running, then download the model used by the bot:

```bash
ollama pull qwen3:4b
```

You can verify it locally with:

```bash
ollama run qwen3:4b
```

### 5. Choose an external LLM provider

For OpenAI-compatible APIs, set:

```env
LLM_PROVIDER="openai-compatible"
LLM_API_BASE_URL="https://api.example.com/v1"
LLM_API_KEY="your_api_key"
LLM_MODEL="provider/model-name"
```

For NVIDIA NIM hosted APIs, set:

```env
LLM_PROVIDER="nvidia"
NVIDIA_API_KEY="your_nvidia_api_key"
NVIDIA_BASE_URL="https://integrate.api.nvidia.com/v1"
NVIDIA_MODEL="openai/gpt-oss-120b"
```

### 6. Run the bot

Using `uv`:

```bash
uv run python main.py
```

Using Python directly:

```bash
python main.py
```

If everything is configured correctly, the console will print:

```text
Bot is running...
```

## Docker

Build the image:

```bash
docker build -t chat-telegram .
```

Run the bot with your `.env` file:

```bash
docker run --rm --env-file .env chat-telegram
```

When Ollama is running on your host machine, set `OLLAMA_HOST` in `.env` so the container can reach it:

```env
OLLAMA_HOST="http://host.docker.internal:11434"
```

You can also run the bot with Docker Compose:

```bash
docker compose up --build bot
```

To run an Ollama container alongside the bot, use the `ollama` profile and point the bot at the Compose service:

```bash
OLLAMA_HOST=http://ollama:11434 docker compose --profile ollama up --build
```

After the Ollama service starts, pull the configured model inside that service:

```bash
docker compose --profile ollama exec ollama ollama pull qwen3:4b
```

## Environment Variables

- `TELEGRAM_TOKEN`: Telegram bot token generated by BotFather.
- `LLM_PROVIDER`: LLM backend. Supported values: `ollama`, `openai-compatible`, `nvidia`. Defaults to `ollama`.
- `LLM_MODEL`: Model used by OpenAI-compatible providers.
- `LLM_API_BASE_URL`: Base URL for a generic OpenAI-compatible API, for example `https://api.example.com/v1`.
- `LLM_API_KEY`: API key for a generic OpenAI-compatible provider.
- `LLM_REQUEST_TIMEOUT_SECONDS`: HTTP request timeout for external providers. Defaults to `60`.
- `OLLAMA_MODEL`: Ollama model used for chat responses. Defaults to `qwen3:4b`.
- `OLLAMA_THINK`: Enables Ollama thinking mode when supported by the model. Defaults to `true`.
- `OLLAMA_HOST`: Ollama server URL. Use `http://host.docker.internal:11434` for host Ollama from Docker, or `http://ollama:11434` when using the Compose Ollama service.
- `NVIDIA_API_KEY`: API key for NVIDIA NIM hosted APIs.
- `NVIDIA_BASE_URL`: NVIDIA NIM OpenAI-compatible API base URL. Defaults to `https://integrate.api.nvidia.com/v1`.
- `NVIDIA_MODEL`: NVIDIA model ID. Defaults to `openai/gpt-oss-120b`.

## Notes

- Conversation history is stored in memory, so restarting the process clears all chat context.
- The bot currently responds only to plain text messages that are not Telegram commands.

## Security

- Do not commit real Telegram tokens to the repository.
- If a token has already been exposed, revoke it in BotFather and generate a new one.
