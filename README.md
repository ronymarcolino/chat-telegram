# chat-telegram

A Telegram bot that uses a local Ollama model to answer messages. The bot runs with `python-telegram-bot`, keeps a per-chat conversation history in memory, and sends each user message to a local LLM through Ollama.

## How It Works

1. A user sends a message to the Telegram bot.
2. The bot stores the message in the chat history for that Telegram chat.
3. The message history is sent to Ollama using the `chat()` API.
4. The model response is returned to the user in Telegram.

The current implementation uses the `qwen3:4b` model and polling mode.

## Requirements

- Python 3.13+
- [uv](https://docs.astral.sh/uv/) or `pip`
- [Ollama](https://ollama.com/) installed and running locally
- A Telegram bot token from BotFather

## Setup

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd chat-telegram
```

### 2. Create the environment file

Create a `.env` file in the project root:

```env
TELEGRAM_TOKEN="your_telegram_bot_token"
```

### 3. Install dependencies

Using `uv`:

```bash
uv sync
```

Using `pip`:

```bash
pip install -e .
```

### 4. Start Ollama and pull the model

Make sure the Ollama service is running, then download the model used by the bot:

```bash
ollama pull qwen3:4b
```

You can verify it locally with:

```bash
ollama run qwen3:4b
```

### 5. Run the bot

Using `uv`:

```bash
uv run python main.py
```

Using Python directly:

```bash
python main.py
```

If everything is configured correctly, the console will print:

```text
Bot is running...
```

## Environment Variables

- `TELEGRAM_TOKEN`: Telegram bot token generated by BotFather.

## Notes

- Conversation history is stored in memory in `user_conversations`, so restarting the process clears all chat context.
- The bot currently responds only to plain text messages that are not Telegram commands.
- The Ollama model name is hardcoded in [`main.py`](c:\dev\repos\chat-telegram\main.py).

## Security

- Do not commit real Telegram tokens to the repository.
- If a token has already been exposed, revoke it in BotFather and generate a new one.
